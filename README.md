# 🏨 Smart Hotel Reservation System

A modern Hotel Reservation & Management System developed using **ASP.NET Core MVC**. The application provides a complete hotel booking experience with secure authentication, AI-powered room recommendations, and an administrative management dashboard.

---

## 📖 Overview

Smart Hotel Reservation System is designed to simplify hotel operations while providing customers with an intuitive booking experience.

Customers can:
- Browse available rooms
- Book hotel rooms online
- Receive AI-powered room recommendations
- Manage their reservations
- View booking history

Administrators can:
- Manage hotel rooms
- Confirm or cancel bookings
- Monitor hotel statistics
- Generate reports
- Manage customers

---

## ✨ Features

### 👤 Customer Features

- User Registration & Login
- Secure Authentication (ASP.NET Identity)

### 👨‍💼 Admin Features

- Revenue Monitoring

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/PARZIVAL283/SmartHotelSystem.git
```

### Open the project

```text
Visual Studio 2026 Preview
or
Visual Studio 2022 (.NET 9 compatible)
```

### Restore packages

```bash
dotnet restore
```

### Apply database migrations

```bash
dotnet ef database update
```

### Run

```bash
dotnet run
```
